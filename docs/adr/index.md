# Architecture Decision Records

ADRs capture structural decisions and the reasoning behind them, so the
"why" survives even after the code (or the person who wrote it) changes.
Use the [template](template.md) for new ADRs — number them sequentially and
never renumber or delete an existing one; supersede it instead.
